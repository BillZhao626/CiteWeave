# Third-party records

The root MIT license covers original CiteWeave material. It does not replace the licenses of dependencies, models, PDF.js assets or standard excerpts. This local release candidate distributes source and original demo material, not dependency wheels, node_modules, model weights, database snapshots or third-party PDF originals. Users install the pinned upstream packages/images themselves.

The historical M3 installed dependency inventory and CycloneDX 1.6 SBOM were generated by `scripts/dependency_inventory.py` in `docs/reports/m3-dependencies.json` and `m3-sbom.cdx.json`. Those historical records list 298 installed Python app/dev/model and frontend build components with declared license metadata and available notice hashes. They do not certify the current candidate. Current lockfiles bind the current dependency resolution; install upstream notices with those packages. Historical generated inventories are excluded from the current source candidate. This is a flat inventory, not a complete transitive operating-system or CUDA binary SBOM; an empty unresolved-metadata list is not a legal audit or a vulnerability scan.

Some build-only packages and native optional packages do not include a standalone LICENSE in their installed npm folder; their metadata/license/source are retained in the notice index. These unmodified tool binaries and their node_modules folders are excluded from the source candidate. Do not publish rebuilt dependency binaries or container images under the application license without separately satisfying their upstream distribution terms.

Gitleaks is an external verification tool downloaded locally from its official v8.30.1 release, checksum verified; its executable is excluded from the candidate. The release check records scanner version, scope and findings separately. Existing M0/M1/M2 manifests are historical verification evidence, not certificates for later modified source.

## Independent public telecom source metadata

The approved release-source manifest is `corpus/public_telecom_manifest.json`. RFC PDFs retain their IETF Trust copyright/TLP notices; MQTT 5.0 OS retains the OASIS Notices. Complete source PDFs, extracted standards text, vectors and bulk chunks are not distributed here. The downloader stores verified official bytes privately. Original structural fixtures are CC0-1.0. See `docs/data/public_telecom_sources.md` and the corpus-delta ADR.
