# Product inspection and local release candidate

This change exposes accepted structural retrieval and durable evaluation through
the existing React workbench. It does not redesign C1–C4 behavior or promote
answer quality. Ask offers the structural profile and source scope while keeping
the legacy default. SSE provisional output stays unvalidated until final; the
existing combined retrieval/reranking stage is shown as combined, not as invented
independent backend progress events.

Read-only endpoints expose bounded node context, case provider/outbox facts and
live Redis PING/version. Existing ownership authorization applies. Node context
uses original span IDs and geometry; it is source inspection, not a claim that a
QueryRun cited the node. Final citations still resolve through the run-authorized
evidence API. No schema migration or provider policy change is required.

The trace separates RetrievalChild ranks/seeds from EvidencePack spans. Parent
headings/siblings have provenance but no fake ranks. Missing BGE, source gaps,
unknown outcomes and absent judgments remain explicit. Retry presentation is
descriptive; only the existing PostgreSQL scheduler can authorize execution.
Historical API/read paths remain available.

Acceptance uses a real browser against real APIs, accepted source artifacts and
original PDF bytes. Engineering generation is explicitly mocked and labeled;
fault-state screenshots use recorded fault fixtures with a visible fixture label.
Private screenshots are raw source assets for later portfolio work, not a final
portfolio PDF. Model quality, sealed Holdout, capacity promotion and Stage D are
outside this gate.

The candidate uses explicit document paths rather than recursively publishing
all documentation. Credentials, local machine paths, private audits, downloaded
PDFs, runtime exports and bulk standards text are excluded. Historical evidence
is retained locally without being relabeled as current acceptance. The candidate
manifest binds source hashes, locks and commit/tree identity; no remote release
or tag is created. Rollback may use a compatible older frontend while preserving
new backend read semantics and immutable evidence.
