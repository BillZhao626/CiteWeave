# M1 已知限制

1. 单人本机 alpha：管理员 token / cookie；没有 SSO、RBAC、多租户运营或公网 HTTPS 部署验收。workspace 隔离通过测试，不等于完整权限产品。
2. PDF 仅覆盖可提取文字的简单文档；没有 OCR、多栏阅读顺序、复杂表格解析。裁剪页面和非零 MediaBox 原点明确拒绝。M0 已验证普通与旋转坐标，不承诺所有 PDF 兼容。
3. 每 KB 最多 10 个逻辑文档，每 PDF 10 MiB / 100 页 / 1000 chunks；chunk 和问题最多 160 codepoints。模型 token 溢出拒绝；query 和网关各限单并发。未做持续高负载或 CPU-only 性能验收。
4. BM25 按文档版本统计，不是全 KB IDF；Qdrant 每尝试一个 collection。废弃索引和 blob 尚无自动 GC；没有回滚 UI。旧版本保留，失败更新不替换有效版本。
5. 已测 worker 故障通过 outbox、租约、fence 只发布一份有效结果，不声称 exactly-once。磁盘损坏、备份恢复、长时间断电和跨机故障未验证。
6. 引用标签、原文和坐标会校验；没有 claim-level entailment 认证。Prompt 防御不等于已解决所有文档提示注入风险。
7. ¥50 仅约束本应用估算与预留，不是供应商账单硬限制；项目外同 key 开销不可见。失联 / 不确定重试保留预留，没有账单对账 UI。价格变化需更新带日期费率卡。
8. 工作台一次展示一个问题结果，刷新不恢复聊天历史；run 可经 API 获取。已有候选 trace，没有完整 tracing、指标平台、批量评测、通用缓存或熔断器。
9. 原创小语料不代表真实公开业务集效果。已验空库迁移和本机重启，未在第二台新机器重装。尚未发布 GitHub、选择个人开源许可证或生成完整 SBOM；不作权属保证。

测试保留 Starlette/httpx、AnyIO 两条上游弃用警告，后续升级处理，没有静默屏蔽。
