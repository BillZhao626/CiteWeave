# Provenance and publication boundary

CiteWeave is an independently implemented personal application. An early planning review included a prior project, so this work is not described as a formal clean-room process. Implementation uses this project’s specifications, original fixtures and public APIs. Former employer/lab source, credentials and private corpora are excluded.

Current React/Celery/BGE/Qdrant implementation does not prove historical delivery timing, model execution or a FAISS migration. General Assistant V2 is high-level historical context only; its private material is not shipped.

Original source uses MIT. Third-party excerpts and model/dependency terms remain separate: see [third-party notices](../THIRD_PARTY_NOTICES.md), [corpus policy](CORPUS.md), and [data notices](DATA_NOTICES.md).

Public-source evaluation questions and annotations include AI-assisted material. Owner-submitted historical review assets are not independent human research labels; old run identities are retained only for technical fixture compatibility. They do not establish current accuracy or general Judge calibration. Private machine paths and runtime reports are excluded from the publication history.
