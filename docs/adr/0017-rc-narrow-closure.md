# ADR0017: Narrow Release Candidate contract closure

Status: implemented under Human RC Narrow Closure authorization, 2026-10-02. New paid outputs require external Human review.

The approved reconciled candidate5400a3c has19 Human-PASS and five Human-FAIL cases. These external judgments are authoritative;21 mechanical COMPLETED results do not imply semantic correctness. Preserve all earlier campaigns, outputs, labels and the unresolved historical UNKNOWN exposure.

The four failure classes are inherited subject loss, unsupported State provenance, unnecessary topic transition during explicit selection, and inconsistent yes/no polarity. The smallest change is to the model-facing contract. Wire v5 uses the unchanged v4 output schema and decoder, with an additional byte-cap check covering serialized fact-list comma separators. Unknown revisions, missing format context and unapproved generation prompt paths reject before use. Its bounded origin catalog shows exact active State and selected structured History matches with counts; no new identity paths or hidden raw history are introduced. Structural availability does not override correction/supersession eligibility. The prompt requires resolving the inherited subject before selecting topic relation/dependency, and distinguishes returning to older intent from independent shift. A literal task label alone does not resolve a pronoun.

Unresolved entity alternatives remain CLARIFY. Explicit current-turn selection in the same stable head task uses existing continue/resolution semantics. Origin age alone does not imply return. Wrong supplied State IDs still fail, and combined return/shift+correction still fails. The runtime does not rewrite those model decisions. Catalog enumeration is sorted independently of execution UUIDs; unique omission and strict provenance are unchanged.

Generation prompt answer-telecom-rc-v2 retains the original factual/evidence/citation instructions and adds a general requirement that a binary prefix agree with the exact proposition, including negation, modality and conditions. Ambiguous negative questions may use an explicit supported conclusion. There is no natural-language polarity classifier, automatic output repair or second model call: arbitrary prose does not provide a safe general proof of contradiction. Synthetic opposite-polarity fixtures test the contract boundary, not model obedience.

Alternatives rejected: weakening State or topic guards would admit unsupported intent; changing retrieval/ranking would not repair the preserved missing subject; post-hoc topic conversion guesses model intent; a broad yes/no text heuristic risks rejecting correct scoped or negated answers. Expected answers, case IDs and Human labels never enter runtime decisions.
