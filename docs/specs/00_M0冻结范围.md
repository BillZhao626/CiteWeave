## 证据 v0.1

- `Scope` 为 workspace_id、kb_id、revision_id 三元组。证据只能在服务端已授权作用域中解析；传入的引用不得提供其自己的可信原文。
- `EvidenceSpan.id` 为服务端确定性 UUIDv5；source_sha256、canonical_text_sha256、normalizer_revision、block_id、起止偏移绑定身份。引用文本严格等于规范文本的 `[start_offset,end_offset)`。
- offset 单位为 Unicode code point；浏览器用 `Array.from(text)` 转换，禁止直接拿 offset 截取 JavaScript string。
- PDF 使用旋转后显示页左上角、0–1 归一化坐标。局部引用必须提供逐字符映射；缺映射时仅能绑定整块，不制造局部精确坐标。
- `table_cell` 显式携带表编号、行列索引、行标题和列标题。本轮验证的是结构化 JSON 表格；PDF 表格、合并单元格、OCR、复杂多栏和任意旋转不在认证范围。
- `support_status=not_assessed`：精确引用不表示已经验证答案主张。M0 不产生模型答案。

## 检索 v0.1

- 中文 analyzer：jieba 0.42.1 精确模式、HMM=false，英文小写，保留 HTTP/2、38.331 等标识符。词表与 IDF 在不可变 snapshot 内拟合；新增文档必须生成新 snapshot。
- BM25：k1=1.5、b=0.75，IDF=ln(1+(N-df+0.5)/(df+0.5))。文档 sparse 保存 TF 长度归一化值，查询 sparse 保存 IDF；Qdrant dot product 与本地公式对照。禁止叠加服务端二次 IDF。
- dense/sparse 都必须使用 workspace、KB、revision 过滤。两个通道各取 40，应用层 RRF：一基排名，k=60，每路同 ID 一票，同分按 ID 排序；重排前取 20。
- 当前个人硬件基线：multilingual-e5-small，query:/passage: 前缀、L2 归一化、384 维；BGE reranker v2-m3 独立进程 FP16、batch=4。模型/分词器 revision 写入报告。max_length=256 仅为短文本 PoC 参数，不能套用为全文语料质量结论。
- `RetrievalProfile` 后续须包含模型、parser、analyzer、chunking、BM25 统计与融合参数摘要；PoC 集合不供正式业务复用。跨库默认各 snapshot 独立检索后融合，不能将不同词表的 sparse index 混写进一个物理集合。
- 只冻结可替换模型接口和本机可运行 profile。BGE-M3 embedding、Qwen reranker、多语真实基准和长文本候选比较留在 M2。

## 任务 v0.1

- PostgreSQL task/outbox 同事务创建；唯一 `(scope, idempotency_key)`，同键不同请求内容返回冲突。
- broker 为唤醒通道，数据库为任务状态真值。发布顺序 send→mark，允许重复投递。
- claim 使用数据库条件更新、递增 fence、带期限租约；heartbeat/commit 都验证 fence 和租约。结果和 completed 状态同事务提交，有效结果唯一。
- Celery late ACK、reject_on_worker_lost、prefetch=1。M0 的 5 秒 visibility_timeout、8 秒 lease 仅用于快速故障注入，禁止直接作为生产超时配置。
- 恢复扫描器从 queued/expired running 补 outbox，独立于旧 worker 的主机名。实验由故障 harness 调用扫描器；持续运行的调度、最大重试、取消、失败终态和外部副作用补偿仍属于后续工作。
- 通过的是 at-least-once + 幂等有效结果，不能宣传 exactly-once。

## M1 首包接口范围

开始实现 `/health/live`、`/health/ready`、`GET/POST /v1/knowledge-bases`：个人管理员 Bearer token，principal workspace 从服务端配置读取；创建要求 Idempotency-Key，201 创建、200 重放、409 内容冲突。名称 1–100 字符、描述最多 1000 字符，禁止额外字段。列表仅返回当前 workspace 的对象。

`/lab/*` 是只含原创 fixture 与本机实验报告的只读工作台，不是正式问答 API。正式文档上传、版本发布、生成、MCP、预算 ledger 和完整权限尚未实现。Web 初期只展示实验与证据，后续逐包接入业务 API。
