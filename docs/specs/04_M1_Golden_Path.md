# M1 Golden Path contract v0.2

Extends M0 evidence/ranking invariants. Pydantic schemas and generated OpenAPI are the implemented API truth. Status: frozen after M1 integration, 2026-09-14. Changes require a spec / ADR update and regression evidence.

- KB: authenticated GET/POST collection and GET by id. Same key/content replays; mismatch 409. Workspace derives from principal. Out-of-scope objects return 404.
- PDF upload: POST `/v1/knowledge-bases/{id}/documents`, raw application/pdf, filename/license declaration and optional document_id as query parameters; Idempotency-Key required. Limit 10 MiB/100 pages/1000 chunks. Only stores blob + document/version/job/outbox in HTTP lifecycle; returns 202. PDF parsing runs in Celery.
- GET document list/detail, GET `/v1/jobs/{id}` return durable stage, attempt, timestamps, errors. New version remains invisible while previous READY version stays usable.
- Job: PENDING → PARSING → CHUNKING → EMBEDDING → INDEXING → READY. Retryable failure/expired lease → RETRY_WAIT → PARSING with a new fence. Maximum 3 attempts; explicit unsupported-format/size/empty-input validation → FAILED_FINAL immediately. Other parser exceptions, including corrupt files, use bounded retries and then FAILED_FINAL. Default lease 30s, heartbeat 7.5s, supervisor scan 2s, maximum retry backoff 30s. Heartbeat and state commits validate the current fence and lease. Partial/stale attempt index never becomes queryable.
- Each document version has immutable canonical blocks/chunks; deterministic chunk IDs. Each attempt writes a distinct physical Qdrant collection. READY transaction publishes only the current fence's collection after verifying count/IDs; prior attempts remain non-effective and can be cleaned later.
- M1 query operates on at most 10 document snapshots per KB, fixed at run start. BM25 IDF/vocabulary are per-version snapshot. Each branch has scope filtering and separate score/rank; app RRF k=60 and reranker choose up to 6 evidence chunks. No unified probability field.
- POST `/v1/queries` creates/replays a durable run; Fetch SSE events: stage, delta (explicit provisional), final (validated), error. One generation per idempotency key; in-progress replay 409. A final result requires known citation labels and exact source spans. Unknown citations fail visibly and provisional output is retracted. No claim-level semantic certification.
- GET `/v1/runs/{id}`, `/v1/evidence/{id}?run_id=...`, `/v1/document-versions/{id}/content`. Reauthorize each request; evidence must belong to run and immutable version. PDF.js uses displayed page coordinates with existing normalized boxes.
- Provider: DeepSeek key from environment only; public official endpoint, bounded timeout/retry. Retry only before a stream starts for 429/5xx/connection failure; uncertain requests retain reserve. Token usage + rate-card estimate are persisted; actual account debit is unavailable unless provider returns it. Project monthly cap ¥50, conservative per-run reservation.
- Local authentication: owner Bearer token or expiring HttpOnly SameSite=Strict local session established with that token. Cookie mutations require same-origin Origin; no secret is embedded in JS. Remote HTTPS deployment is outside this single-machine alpha.
- HTTP error envelope is `{error:{code,message,retryable},request_id}`. SSE errors use StreamEvent.code after headers have been sent. Detailed safe stage/error metadata persists. No background ingestion within FastAPI BackgroundTasks.

M1 input profile: at most 10 logical documents per KB; question/chunk at most 160 Unicode codepoints. E5 384 dimensions / 256 input tokens; BGE pair at most 512 tokens, overflow rejected. PDF cropbox different from mediabox and nonzero media origin are rejected to avoid incorrect viewer mapping. No OCR or complex layout certification.

Query deadline defaults to 45s; one running query globally. Abandoned runs older than 120s become FAILED/api_interrupted while retaining uncertain fee reservations. Terminal final results and citation links are durable. No historical-chat UI, claim entailment guarantee, full circuit breaker or automatic orphan-index GC in M1. See M1_LIMITATIONS.md and M1_ACCEPTANCE.md for tested scope.
