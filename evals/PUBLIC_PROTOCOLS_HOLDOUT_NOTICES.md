# Public protocols holdout: source and authorship notices

`public-protocols-holdout-v1.json` contains original Chinese questions and AI-authored reference answers, with short unchanged source quotations and exact evidence locators. The source quotations retain their respective RFC terms; the project's software license does not replace those terms. The Gold is literal-source-checked, not independently human annotated.

RFC 2606 includes its own full copyright and permission statement. RFC 8174 and RFC 7405 refer to BCP 78 and the IETF Trust provisions in effect at publication. The official [IETF Trust provisions](https://trustee.ietf.org/documents/trust-legal-provisions/) distinguish document text and code components; the [corrected provisions](https://trustee.ietf.org/documents/trust-legal-provisions/tlp-5/) explain the historical BSD license naming correction. ABNF examples in RFC 7405 are attributed here to IETF and RFC 7405. They are source excerpts for evaluation, not a parser implementation.

The downloaded ASCII files and locally typeset PDFs remain under ignored `.runtime/evaluation/holdout-corpus/`. The deterministic renderer retains original page text, authorship, notices and footers. These are local renderings, not RFC Editor publisher PDFs. All 13 pages were visually checked. Neither raw source documents nor model weights are part of the source release candidate. Source/render hashes and transformation parameters are recorded by the holdout freezing scripts.

No new remote publication is performed in this M3 experiment. Preserve these attributions and the source notices when reproducing the evaluation.
